# 約阿施的得勝箭(joash-arrows)

> 列王紀下 13:14-19——以利沙病榻前,約阿施王開朝東的窗戶,射出「耶和華的得勝箭」;
> 再拿箭打地,王打三次便止住了。以利沙發怒:「應當擊打五六次!」
> 3D 聖經射箭遊戲(archery3d 引擎換皮),HFPC 主日學系列。

## 玩法

- **得勝的箭(故事模式)**:①在以利沙的病房裡朝東窗射箭,射中亞蘭軍旗靶
  ②拿箭打地——遊戲不告訴你該打幾次,你自己決定何時「住手」:
  打滿 5 次以上=「直到滅盡他們」完全得勝;不到 5 次=溫柔的「止住了」結局+王下13:19 經文教學。
- **亞弗之戰**:6 回合 × 3 箭計分賽,滿分 180。
- **王的練弓場**:無限箭數自由練習。

拉弓蓄力、準星晃動(屏息越久越晃)、順逆風補償、拋物線箭道、十環計分;
五難度(幼兒~職業)。判定=畫面:放箭當下先算命中點,再把箭演到那個點。

## 操作

按住(畫面/空白鍵)=拉弓,移動=瞄準,放開=放箭;打地幕:點畫面/空白鍵=擊打,「住手」鈕=停止;V=視角,Esc/P=暫停。

## 開發

```bash
npm install
npm run dev      # 本機試玩(dev 不註冊 SW)
npm run build    # 產物在 dist/
node scripts/gen-voice.mjs  # 烤人聲(雲哲旁白+曉臻經文;產物進 git,離線可玩)
```

- 人聲鐵律:預烤 mp3(msedge-tts),缺檔只出字幕,絕不用 Web Speech 機器聲。
- 經文:和合本,已用 cuv MCP 查驗(王下13:14-19)。
- PWA 可離線、可安裝;SW=網路優先 HTML+快取優先資產。
